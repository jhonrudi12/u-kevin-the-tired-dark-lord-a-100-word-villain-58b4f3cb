A 104-word monologue spoken by a fantasy villain who is secretly just very tired. The tiredness lives in the voice, the rhythm and the small deflections — the half-finished sentences, the reused eclipse speech, the paperwork of ruling the Nine Valleys — never in a plain statement that he is weary. He is still a villain: a history (ruler of the Nine Valleys), a scheme (tonight's ritual, moon and dagger), and a plan to go through with it all — right after one cup of tea. `main.ts` writes the monologue deterministically to `/output/entry.txt`, with no network and no input files.

## Run it

```sh
node main.ts
```
